ROYAL TABLE - النسخة التجريبية الأولية

تشغيل:
1) فك ضغط الملف.
2) افتح index.html لمعاينة الموقع (بعض المكتبات والصور تحتاج إنترنت).
3) لتثبيت لوحة الإدارة كتطبيق PWA، ارفع المجلد على استضافة تدعم HTTPS مثل GitHub Pages.
4) افتح الموقع من Chrome على الهاتف، ثم استخدم زر "تثبيت التطبيق" أو قائمة المتصفح > إضافة إلى الشاشة الرئيسية.

رموز الدخول التجريبية:
المدير: 2017
العامل: 2015

الصلاحيات:
- المدير: إضافة المنتجات وحذفها وتعديل الأسماء والتصنيفات والأسعار وروابط الصور.
- العامل: متابعة الطلبات وتغيير حالتها ومراجعة السجلات.
- الطلبات وسجل العمليات والمنتجات تحفظ محلياً في المتصفح باستخدام LocalStorage.

مهم جداً قبل الاستخدام الحقيقي:
هذه نسخة Front-end تجريبية. البيانات لا تتزامن بين أجهزة العملاء والموظفين، ورموز الدخول موجودة في كود الواجهة وليست حماية إنتاجية. لتشغيل مطعم فعلي يلزم Backend وقاعدة بيانات ومصادقة آمنة وصلاحيات على الخادم، وربط الطلبات الفورية والإشعارات. لا تستخدم رموز PIN الحالية كحماية حقيقية.

تحديث قائمة الطعام: تمت إضافة 8 أقسام، في كل قسم 15 طبقاً (120 طبقاً إجمالاً). في قسم "الكل" تظهر 8 أطباق أولاً ويمكن الضغط على زر "المزيد" لإظهار دفعات إضافية. عند تحديث نسخة الموقع، تُضاف الأصناف الجديدة إلى بيانات المتصفح الموجودة دون حذف المنتجات التي عدلها المستخدم سابقاً.

تحديث الصور:
- تم تعيين رابط صورة مختلف لكل طبق من الأطباق الـ120، باستخدام كلمات مفتاحية مرتبطة بنوع الطبق ومعرّف فريد لتجنب تكرار روابط الصور.
- الصور تُحمّل من خدمة صور خارجية (LoremFlickr)، لذلك يلزم اتصال إنترنت، وقد يختلف مدى تطابق الصورة مع الطبق أو توفرها بحسب الخدمة.
- يمكن للمدير استبدال صورة أي طبق من لوحة المنتجات بإدخال رابط صورة مباشر.
