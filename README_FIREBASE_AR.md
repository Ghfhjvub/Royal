ROYAL TABLE – تحديث تتبع الطلبات والوضعين وخدمة الطاولات
Firebase Project: hassony-c71fc

التحديثات:
- تتبع مباشر للطلب باستخدام رمز عشوائي من 16 حرفاً/رقماً.
- العميل يستطيع قراءة مستند تتبع واحد برمزه فقط؛ لا يستطيع استعراض قائمة الرموز أو قراءة مستندات الطلبات.
- عند تغيير الحالة من لوحة الإدارة يتم تحديث حالة التتبع تلقائياً.
- اختيار تناول داخل المطعم مع إدخال رقم الطاولة، ويظهر رقم الطاولة في لوحة الطلبات.
- خيارات استلام من المطعم أو التوصيل.
- زر الوضع الليلي/النهاري مع حفظ الاختيار على الجهاز.
- إزالة حقل الملاحظات من نموذج الطلبات الجديدة.
- لا يستخدم Firebase Storage.

خطوة مطلوبة قبل تشغيل التحديث:
1) افتح Firebase Console > Firestore Database > Rules.
2) استبدل القواعد الحالية بمحتوى firestore.rules المرفق واضغط Publish.
3) ارفع ملفات الموقع المحدثة إلى الاستضافة فوق النسخة السابقة.
4) بعد النشر اختبر طلباً تجريبياً، وتأكد من ظهور رمز التتبع ورقم الطاولة في لوحة الإدارة.

ملاحظة: القواعد الجديدة تمنع قراءة قائمة order_tracking وتسمح بقراءة مستند مفرد فقط عند معرفة رمز التتبع. رموز الطلبات القديمة لا تملك مستندات تتبع؛ التتبع متاح للطلبات الجديدة بعد هذا التحديث.
